# CodeAlpha FAQ Chatbot — Project Report

## Objective
Develop an FAQ chatbot that can identify the closest matching question from a predefined FAQ knowledge base and provide the corresponding answer.

## Approach
The chatbot uses text preprocessing, TF-IDF vectorization, cosine similarity, and a similarity threshold. Common FAQ categories are also handled through direct keyword rules.

## FAQ Areas
- Account creation and registration
- Password reset/change
- Customer support
- Working hours
- Order cancellation
- Order tracking
- General service information

## Interface
Gradio is used to provide a simple browser-based interface.
